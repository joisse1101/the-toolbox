# Proposal

## Why

The story skills look for the backlog data folder in three places: the file the `PLANNER_CONFIG` variable names, a `.plans` folder in the current folder, and a `planner.config.yaml` in the current folder. The config lookups date from before `.plans` existed, when backlogs lived in the planner's own data folder. They tie the skills to the planner's config file, which blocks the planned rename of the planner to a viewer with its own private config. A skill should only work on the backlog of the repo it runs in, which is its `.plans` folder.

## What Changes

- **BREAKING**: A story skill finds the data folder only as `.plans` in the current folder. It no longer reads the `PLANNER_CONFIG` variable or a `planner.config.yaml` file. A backlog kept outside a repo's `.plans` (a plain data folder such as `planner/data/`) can no longer be reached by the skills; the planner portal still reaches it.
- The "no data folder found" and "cannot be used" messages name only `.plans` and stop telling the user to set `PLANNER_CONFIG`.
- The skills' `SKILL.md` files, the script header comments, `/jois-code:archive` and the wiki describe the one place.
- The toolkit's story tests run each script from a temp project folder that holds `.plans`, instead of pointing `PLANNER_CONFIG` at a temp config.
- The generated `lib/` copies in each skill are regenerated by the sync script.
- Unchanged: the planner portal and its tests keep `planner.config.yaml` and `PLANNER_CONFIG` for their own use; renaming them belongs to the later planner-to-viewer move.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `toolkit-story-skills`: the requirement "A story skill finds the data folder in the current folder" is removed and replaced by "A story skill uses only .plans in the current folder".

## Impact

- Code: `planner/logic/skill-support/resolve-data-dir.mjs` and its copies in `toolkit/skills/*/lib/skill-support/`; the header comments of the story scripts in `toolkit/skills/jois-story-*`.
- Skill text: `SKILL.md` of `jois-story-explore`, `jois-story-propose`, `jois-story-review` and `jois-story-plan`; `toolkit/commands/jois-code/archive.md`.
- Tests: `planner/test/logic/resolve-data-dir.test.mjs`; `toolkit/tests/story/*` (about 12 files and `helpers/temp-config.mjs`); `toolkit/tests/test_install_review_only.py` and `test_archive_command.py`.
- Docs: `wiki/planner/Story-Skills.md`, `wiki/planner/architecture/Story-Skills-Internals.md`, `wiki/Story-To-Code.md`.
- Users: anyone who started a skill with `PLANNER_CONFIG` set, or from a folder holding `planner.config.yaml` and no `.plans`, gets "no data folder found" and must start the session in the code base that holds `.plans`. Installed skills change only after the toolkit is reinstalled.
