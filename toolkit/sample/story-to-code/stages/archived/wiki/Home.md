# Habit and focus tracker

A small app that tracks daily habits and runs a Pomodoro focus timer. It keeps its data in browser local storage, so it needs no server.

## What it does today

- A habit list with a daily check-off.
- A Pomodoro timer (25 minutes), with no sound.
- A task category picker (coding, writing, reading).
- Saving to browser local storage (`app/src/storage.ts`).
- The current and the best streak of each habit (`app/src/streak.ts`).
