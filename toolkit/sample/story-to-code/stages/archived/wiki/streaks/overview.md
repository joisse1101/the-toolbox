# Streaks

Each habit on the habit list shows how many days in a row it was checked off, and the longest run it ever had.

| I want to | Do this |
|---|---|
| See how many days in a row I checked off a habit | Open the habit list and read the pill beside the habit: "N-day streak", or "No streak yet" |
| See my longest run for a habit | Read "Best M" beside the pill (under the habit name on a narrow window) |

- The numbers are worked out from the days already checked off, so nothing new is saved.
- A run that ended yesterday still counts until you miss a whole day, so a habit does not drop to 0 each morning.
- Everything stays in the browser. Nothing is sent to a server.

Facts and limits are in the [reference](reference.md). The structure, flows and decisions are in the [design](design.md).
