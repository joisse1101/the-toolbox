# Future Releases

Ideas for features that are not built yet. Each one is a starting point to explore, not a finished story.

## Ideas

- **Category audio scapes.** Ambient sound that matches the task category picked for a focus session. The sound is generated in code with the Web Audio API (white and brown noise), so no recordings are bundled. A person's own sound files in an optional `audio/` folder, which git ignores, replace the generated sound when present.
- **Streaks.** A count of consecutive days a habit was checked off.
- **Weekly stats.** A summary of habit check-offs and focus sessions for the last seven days.
- **Custom timer lengths.** Let a person set the focus length instead of the fixed 25 minutes.
- **Export and import.** Save the habits and history to a file and load them back.

Nothing yet. A feature moves here from Ideas when its slice is archived.
