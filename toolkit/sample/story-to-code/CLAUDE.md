# CLAUDE.md

This file guides Claude Code in the habit and focus tracker, a small Vite, TypeScript and Tailwind CSS app that keeps its data in browser local storage.

## Commands

Run these from `app/`, which holds `package.json` and `package-lock.json`.

```
npm ci          # install
npm run build   # type-check and build to app/dist/
npm run dev     # dev server
npm test        # unit tests (Vitest)
```

## Where the docs are

Docs live in `wiki/`, one page per topic, starting at `wiki/Home.md`. Read the page for your topic before you change the code it describes, and update it in the same change. Planned features are listed in `wiki/Future-Releases.md`.
